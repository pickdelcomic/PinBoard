PICKDEL BOARD HELP

Controls

SELECT
Click and drag objects to move them.

TEXT
Creates a new note. Double-click the blue title to rename it and double-click the text to edit it.

IMAGE
Add an image with a title.

STICKER
Add an image without a box or title.

DRAW
Draw anywhere on the board. Press SELECT when finished.

ERASER
Erase drawings. Press SELECT when finished.

SHIFT + DRAG
Move the board around.

MOUSE WHEEL
Zoom in and out.

RIGHT CLICK
Delete or duplicate an object.

DELETE
Deletes the selected object.

SAVE AS
Creates a new board file.

LOAD
Opens another board file.
