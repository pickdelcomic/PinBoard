PICKDEL BOARD

Controls

SELECT
Select and move objects.

TEXT
Creates a new note.

IMAGE
Adds an image with a title.

STICKER
Adds an image without a title.

DRAW
Draw on the board.

ERASER
Erase drawings.

W A S D
Move around the board.

ARROW KEYS
Also move around the board.

SHIFT + DRAG
Move around the board.

MOUSE WHEEL
Zoom in and out.

RIGHT CLICK
Open object options.

STYLE
Customize the board and selected objects.

PIXEL MODE
Makes images use crisp nearest-neighbor scaling.

DELETE
Delete the selected object.
