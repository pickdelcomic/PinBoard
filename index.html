PICKDEL BOARD HELP

Controls

SELECT
Select and move objects.

TEXT
Creates a new note.

IMAGE
Adds an image with a title.

STICKER
Adds an image without a box or title.

PIXEL
Makes images use hard nearest-neighbor pixels instead of smooth scaling.

DRAW
Draw on the board.

ERASER
Erase drawings.

SHIFT + DRAG
Move around the board.

MOUSE WHEEL
Zoom in and out.

RIGHT CLICK
Open object options.

RIGHT CLICK → LAYER
Move objects in front of or behind other objects.

DELETE
Delete the selected object.

SAVE AS
Save the board as a new file.

LOAD
Load another board.
