PICKDEL BOARD

Controls

SELECT
Select and move objects.

TEXT
Creates a new note.

IMAGE
Adds an image with a title.

STICKER
Adds an image without a title or border.

DRAW
Draw on the board.

ERASER
Erase drawings.

WASD
Move around the board.

ARROW KEYS
Also move around the board.

SHIFT + DRAG
Move around the board.

MOUSE WHEEL
Zoom in and out.

RIGHT CLICK
Open object options.

CLICK EMPTY SPACE
Deselect objects.

PIXEL MODE
Makes pixel-art images use crisp nearest-neighbor scaling.

DELETE
Delete the selected object.

CTRL + D
Duplicate the selected object.

BG IMAGE
Add an image behind your board.

BG TILE
Toggle whether the background image repeats.

SAVE / LOAD
Boards are saved as portable JSON files that can be shared with other people.
